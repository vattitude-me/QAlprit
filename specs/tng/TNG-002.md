# TNG-002: onboarding from a clean app to the ID check

Clears the app and opens a savings account: debug menu, sign up, SMS code, passcode, name, date of birth, address, email code, tax questions, then the ID scan and selfie done by a person on the phone. The last step fails if the app says it could not verify the person.

Before a real run:

- Set `TNG_PHONE` and `TNG_EMAIL` in `.env`. The SMS and email codes go there and are typed in the Workbench when the run asks.
- Replace the name, date of birth and address with the details on the ID you will scan, or the identity check fails.
- Use a phone number with no application saved on the server. A number that already has one skips the detail screens and the run stops at the name form.
