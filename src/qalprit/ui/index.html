2. Identify Screens & Map Element Locators

Every screen in your app has buttons, text fields, and labels. Capture a screen directly from a live device or paste a UI XML dump, pick clean names (like login.email_input), and save them to screens/screens.yaml.

Option A: Capture Live Device Screen

Launches Appium briefly on the chosen device, reads the active XML screen hierarchy, and ranks tappable/editable elements.

Option B: Inspect XML Dump (Offline / Sample)

Paste XML from UIAutomator, Appium Inspector, or a failure *_FAIL.xml dump — great for offline mapping or testing right now.

Review & Save Identified Elements

Check the elements you want to automate, adjust the key name (e.g. email_input, submit_btn), mark Sensitive on password/PIN fields to auto-mask secrets, and save.
